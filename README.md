This repo is a port of Vivify [only for PC] to quest! 

# Features
 an on-device PC → Quest converter, with its own DirectX → GLSL shader
  translator
  AudioLink [42-flux doesnt work]

  # How to install
  1: Download the lastest .qmod from the releases.
  2: Go to https://mbf.bsquest.xyz/ and connect your quest.
  2: Click add a mod and put the .qmod
  3: Your done! Now go in game and try a Vivify map!
